# JSON Data Processor

## 📌 Project Description

This Python program is used to read, process, search, filter, and summarize data stored in a **JSON file**.

The program performs the following operations:

* Reads data from a JSON file
* Displays all records
* Searches records by name
* Filters employees whose salary is greater than `30000`
* Calculates total number of records
* Calculates total salary
* Calculates average salary
* Handles common file and JSON errors

---

## 🛠️ Technologies Used

* **Python 3**
* **JSON**
* Python `json` module

---

## 📂 Required JSON File Format

The JSON file should contain records like this:

```json
[
    {
        "name": "Rahul",
        "salary": 35000
    },
    {
        "name": "Aman",
        "salary": 28000
    },
    {
```
